닥터검역 고객 링크 공유 운영 안내
================================
관리자는 Google 로그인으로 고객을 등록·수정합니다.
고객은 계정 연결이나 로그인 없이 전용 링크로 진행 현황을 확인합니다.

이번 변경에 필요한 작업
----------------------
1. Firebase Console > dr-quarantine-consultations > Firestore > 규칙
   저장소의 firestore.rules 전체 내용으로 교체하고 게시합니다.
   GitHub Pages 배포만으로 Firebase 보안 규칙이 게시되지는 않습니다.
2. admin.html을 강력 새로고침한 뒤 관리자 Google 로그인.
3. 고객을 선택하고 '고객 링크 공유'를 체크한 상태로 저장.
   기존 고객도 한 번 저장하면 새 링크가 생성됩니다.
4. 생성된 URL을 복사해 고객에게 전달. 고객 계정 UID 입력은 필요 없습니다.

Firebase 규칙 게시 전에도 고객 원본 저장은 유지됩니다.
공유 문서 생성 권한이 없으면 '고객 저장 완료 · 공유 링크 생성은 실패했습니다'와 안내가 표시됩니다.
규칙을 게시한 뒤 다시 저장하면 됩니다.
실제 Firebase의 공유용 규칙 게시와 로그인 없는 조회 테스트는 사용자 게시 후 확인해야 합니다.

공유 범위
---------
반려동물명, 국가, 출국일, 다음 방문일, 다음 준비사항, 진행 단계, 완료 여부, 고객 안내 메모.
보호자명, 고객/관리자 계정 UID, 작성자/수정자 기록, 원본 고객 ID는 공유 문서에서 제외합니다.
memo는 고객에게 보여줄 안내 내용입니다. 내부 기록이나 연락처를 넣지 마세요.
링크를 가진 사람에게 위 진행 현황이 표시됩니다.

링크 관리
---------
URL: https://pet-travel.co.kr/travel.html#token=<64자리 무작위 토큰>
암호학적 난수 32바이트(256비트)를 사용합니다.
토큰은 URL fragment에 두어 HTTP 요청 경로에 전송되지 않습니다.
공유 문서는 마지막 저장일부터 180일간 조회할 수 있습니다. 다시 저장하면 기간이 갱신됩니다.
'고객 링크 공유' 체크를 해제하고 저장하면 공유 문서가 삭제되어 기존 링크 접근이 중지됩니다.
고객 삭제도 원본, 공유 문서, 연결 정보를 함께 삭제합니다.
공유를 다시 켜면 같은 토큰으로 재공유됩니다.
이미 전달된 내용/화면 캡처를 회수하는 기능은 없습니다.

문서 구조
---------
travelCustomers/{customerId}: 관리자 전용 원본. 기존 필드 구조 유지(customerUid는 빈 문자열).
travelShareLinks/{customerId}: 관리자 전용 {token, enabled, updatedAt}.
travelShares/{randomToken}: 위 공유 범위와 {active, expiresAt, updatedAt}.
travelShares는 단건 조회만 허용합니다. 목록 조회 및 고객의 쓰기는 차단합니다.
기존 consultations 상담 접수·관리 규칙은 유지합니다.

기존 로컬 데이터
---------------
예전에 고객을 입력했던 동일 브라우저·기기·도메인에서 '이 브라우저의 기존 고객 가져오기'.
localStorage 원본은 지우지 않고 이미 등록된 ID는 건너뜁니다. 김하늘/몽이 기본 샘플은 제외합니다.
새 고객과 수정 정보는 Firestore에 저장되며 GitHub 저장소에는 저장되지 않습니다.

검증
----
배포 전 모의 Firestore로 공개 문서 개인정보 제외, 무작위 토큰, 만료, URL 유지,
수정 반영, 공유 중지, 삭제 정리, 규칙 미게시 시 원본 저장 보존, 관리자 인증 차단을 검증했습니다.
실제 Firebase 익명 공유 조회 및 관리자 CRUD는 새 규칙 게시 후 추가 확인이 필요합니다.
